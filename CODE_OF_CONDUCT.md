# Code of Conduct

## Our commitment

We are committed to making participation in this project a harassment-free experience for everyone.

## Expected behavior

- Be respectful and constructive.
- Assume good intent and communicate with empathy.
- Accept feedback gracefully.

## Unacceptable behavior

- Harassment, insults, or discrimination.
- Trolling, personal attacks, or deliberate intimidation.
- Publishing private information without consent.

## Enforcement

Project maintainers may remove comments, commits, issues, or pull requests that violate this code and may ban repeat offenders.

## Reporting

Report incidents to: `security@react-fun-with-flags.dev`.
